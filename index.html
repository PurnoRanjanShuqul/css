Syntax & Basic Rules

Must Master
Highest Priority Most Used

1. CSS Rule Structure

selector + property + value
Detailed Essential Note

CSS rule মূলত selector, property, এবং value দিয়ে তৈরি হয়। Selector target ঠিক করে, property style-এর ধরন বলে, আর value style-এর actual মান দেয়। সব CSS rule এই basic pattern follow করে।

When / Where to Use

CSS-এর প্রতিটি styling rule লেখার সময় এই structure-ই ব্যবহার হয়। এটা CSS-এর foundation।

Pro Tip / Common Mistake

Semicolon বা curly brace ভুলে গেলে পুরো rule কাজ নাও করতে পারে। শুরুতেই syntax discipline তৈরি করো।

Example
h1 {
  color: blue;
  font-size: 32px;
}
Important Mid Use

2. Ways to Use CSS

inline, internal, external
Detailed Essential Note

CSS তিনভাবে use করা যায়: inline, internal, external। Real project-এ external CSS সবচেয়ে clean, reusable, এবং maintainable solution।

When / Where to Use

Small demo-তে internal বা inline দেখা যায়, কিন্তু production site-এ mostly external stylesheet use করা হয়।

Pro Tip / Common Mistake

Beginners অনেক সময় সব style inline লেখে, এতে code messy হয়ে যায়। শুরু থেকেই external CSS practice করো।

Example
<link rel="stylesheet" href="style.css">

Selectors

Must Master
Highest Priority Most Used

3. Basic Selectors

element, class, id, universal
Detailed Essential Note

Selector CSS-এর targeting system। Class selector সবচেয়ে reusable, id selector unique element target করে, আর element selector tag-based styling দেয়।

When / Where to Use

Daily styling-এ class selector সবচেয়ে বেশি use হয়। Specific unique element-এ id লাগতে পারে।

Pro Tip / Common Mistake

Styling-এর জন্য id overuse না করে class use করো। এতে CSS reusable ও scalable হয়।

Example
p { color: #333; }
.box { padding: 20px; }
#title { font-size: 2rem; }
Very Important Mid Use

4. Relationship Selectors

descendant, child, sibling, attribute
Detailed Essential Note

HTML structure অনুযায়ী nested বা related element target করতে relationship selectors দরকার হয়। এটি complex UI-তে খুব useful।

When / Where to Use

Nav-এর direct links, card-এর ভিতরের paragraph, type-based input styling — এসব জায়গায় use হয়।

Pro Tip / Common Mistake

অতিরিক্ত deeply nested selector avoid করো, কারণ এতে CSS maintain করা কঠিন হয়ে যায়।

Example
.card p { color: #555; }
nav > a { text-decoration: none; }
input[type="email"] { border: 1px solid blue; }

Colors & Units

Must Master
Highest Priority Most Used

5. Color Formats

hex, rgb, rgba, hsl
Detailed Essential Note

CSS-এ color অনেক format-এ define করা যায়। Hex সবচেয়ে common, rgba transparency দেয়, hsl theme adjust করতে easy।

When / Where to Use

Text color, background, border, shadow, hover state—সব জায়গায় color use হয়।

Pro Tip / Common Mistake

Random color use না করে consistent color palette রাখো। এতে design professional দেখায়।

Example
body { color: #334155; }
.box { background: rgba(37, 99, 235, 0.1); }
Highest Priority Most Used

6. Size Units

px, rem, em, %, vh, vw
Detailed Essential Note

CSS unit determine করে element কত বড় বা ছোট হবে। px fixed, rem scalable, % relative, vh/vw viewport-based size দেয়।

When / Where to Use

Typography-এ rem, container width-এ %, full-screen section-এ vh, small precise control-এ px useful।

Pro Tip / Common Mistake

সবকিছু px-এ না লিখে responsive thinking নিয়ে unit use করো।

Example
h1 { font-size: 2.5rem; }
.container { width: 90%; }
.hero { min-height: 100vh; }

Box Model

Must Master
Highest Priority Most Used

7. Core Box Model

content, padding, border, margin
Detailed Essential Note

প্রতিটি element box-এর মতো behave করে। Content-এর চারপাশে padding, তার বাইরে border, আর সবচেয়ে বাইরে margin থাকে।

When / Where to Use

Card spacing, section gap, button size, layout breathing space—সব box model-এর উপর depend করে।

Pro Tip / Common Mistake

Margin আর padding confuse করো না—margin বাইরে, padding ভেতরে।

Example
.card {
  padding: 20px;
  border: 1px solid #ddd;
  margin: 20px;
}
Highest Priority Most Used

8. Box Sizing

border-box vs content-box
Detailed Essential Note

border-box use করলে width-এর ভিতরেই padding + border count হয়, ফলে layout calculate করা অনেক সহজ হয়।

When / Where to Use

প্রায় সব modern project-এই globalভাবে border-box use করা হয়।

Pro Tip / Common Mistake

Default content-box রেখে complex layout করলে overflow সমস্যা হতে পারে।

Example
* {
  box-sizing: border-box;
}

Typography

Must Master
Highest Priority Most Used

9. Typography Basics

font-family, size, weight, line-height
Detailed Essential Note

Typography UI readability-এর heart। Font family, size, weight, line-height ঠিক না হলে design সুন্দর হলেও পড়তে খারাপ লাগে।

When / Where to Use

Body text, headings, labels, buttons, form text — সব জায়গায় typography apply হয়।

Pro Tip / Common Mistake

Line-height খুব কম দিলে text crowded লাগে, বেশি দিলে loose লাগে। Balanced রাখো।

Example
body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
}

h1 {
  font-size: 3rem;
  font-weight: 700;
}
Important Mid Use

10. Text Control

text-decoration, transform, align
Detailed Essential Note

Text presentation আরও clean করতে decoration remove, uppercase transform, alignment change ইত্যাদি use হয়।

When / Where to Use

Nav links, headings, button text, card titles, centered section content-এ useful।

Pro Tip / Common Mistake

সব text uppercase করলে readability কমে যেতে পারে। প্রয়োজন অনুযায়ী use করো।

Example
a { text-decoration: none; }
h2 { text-transform: uppercase; }

Display & Visibility

Must Master
Highest Priority Most Used

11. Display Basics

block, inline, inline-block, none
Detailed Essential Note

Element layout-এ কীভাবে behave করবে তা display property control করে। Block full width নেয়, inline content-width নেয়, inline-block mix behavior দেয়।

When / Where to Use

Buttons, hidden content, menu items, card alignment—এসব জায়গায় display খুব common।

Pro Tip / Common Mistake

শুধু element hide করার জন্য display:none use করলে space-ও disappear হয়। এটা intentional কিনা বুঝে use করো।

Example
.btn { display: inline-block; }
.hidden { display: none; }
Important Mid Use

12. Overflow Handling

overflow, ellipsis
Detailed Essential Note

Container-এর content বেশি হলে overflow control করে visible থাকবে, hide হবে, নাকি scroll হবে।

When / Where to Use

Long title, modal content, fixed height card, code container, table wrapper-এ useful।

Pro Tip / Common Mistake

text-overflow: ellipsis use করতে white-space এবং overflow rule-ও properly set করতে হয়।

Example
.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Positioning

Must Master
Highest Priority Most Used

13. Position Property

relative, absolute, fixed, sticky
Detailed Essential Note

Position property document flow-এর বাইরে বা ভেতরে element-এর exact placement control করতে সাহায্য করে।

When / Where to Use

Badge, overlay, sticky navbar, floating button, tooltip positioning-এ use হয়।

Pro Tip / Common Mistake

Absolute element সঠিকভাবে কাজ করাতে parent-এ অনেক সময় relative দিতে হয়।

Example
.parent { position: relative; }
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
Very Important Mid Use

14. Z-Index & Layering

stack order
Detailed Essential Note

Multiple overlapping element-এর মধ্যে কোনটা সামনে থাকবে, সেটা z-index control করে।

When / Where to Use

Modal, dropdown, tooltip, sticky nav, overlay element-এ use হয়।

Pro Tip / Common Mistake

z-index কাজ না করলে first position context check করো।

Example
.modal {
  position: fixed;
  z-index: 1000;
}

Flexbox

Must Master
Highest Priority Most Used

15. Flex Container

justify-content, align-items, gap
Detailed Essential Note

Flexbox row বা column direction-এ items align, center, distribute করা খুব সহজ করে দেয়।

When / Where to Use

Navbar, button group, cards row, hero split layout — সবখানে flexbox খুব common।

Pro Tip / Common Mistake

Main axis আর cross axis concept clear রাখো, নাহলে justify-content আর align-items confuse হবে।

Example
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
Very Important Mid Use

16. Flex Item Control

flex-grow, basis, order
Detailed Essential Note

Flex item property দিয়ে child item-দের individual behavior control করা যায়।

When / Where to Use

Featured card বড় করা, specific item আগে আনা, available space distribute করা—এসব ক্ষেত্রে useful।

Pro Tip / Common Mistake

Flex-grow use করার সময় parent width এবং gap-এর effect মাথায় রাখো।

Example
.item { flex: 1; }
.featured { order: -1; }

Grid

Must Master
Highest Priority Most Used

17. Grid Basics

display:grid, columns, gap
Detailed Essential Note

Grid row এবং column দুই direction-এ layout build করতে দেয়। Complex card layout-এর জন্য খুব powerful।

When / Where to Use

Gallery, dashboard, pricing section, card layout — grid perfect choice।

Pro Tip / Common Mistake

Simple one-row alignment-এর জন্য grid নয়, flexbox better হতে পারে। Use case অনুযায়ী choose করো।

Example
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
Important Mid Use

18. Advanced Grid Placement

grid-column, grid-row, span
Detailed Essential Note

Specific grid item-কে বড়, wide, tall, বা custom area-তে place করতে advanced grid placement use হয়।

When / Where to Use

Featured card, asymmetrical layout, magazine UI, dashboard widget layout-এ useful।

Pro Tip / Common Mistake

Grid placement use করার আগে base grid structure clear করো, না হলে item overlap হতে পারে।

Example
.featured {
  grid-column: span 2;
}

Responsive Design

Must Master
Highest Priority Most Used

19. Media Queries

@media, breakpoints
Detailed Essential Note

Media query screen size অনুযায়ী CSS change করতে দেয়, যাতে design mobile, tablet, desktop সবখানে usable থাকে।

When / Where to Use

Grid collapse, font resize, nav stack, section spacing adjust—এসব responsive change-এ use হয়।

Pro Tip / Common Mistake

Desktop-first না mobile-first—একটা consistent approach follow করো।

Example
@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
Highest Priority Most Used

20. Fluid Layout Principles

max-width, width:100%, responsive images
Detailed Essential Note

Responsive layout মানে শুধু media query না, বরং content naturally adapt করাও important। এজন্য fluid container আর responsive image দরকার।

When / Where to Use

সব modern responsive page-এই max-width container এবং responsive image use করা উচিত।

Pro Tip / Common Mistake

Fixed width image use করলে mobile-এ overflow হয়। max-width:100% habit করো।

Example
img {
  max-width: 100%;
  height: auto;
}

.container {
  width: 90%;
  max-width: 1200px;
}

color, image, gradient

Background section hierarchy, hero emphasis, and overall visual appeal improve করতে সাহায্য করে।

When / Where to Use

Outline remove করলে accessible alternative focus style দাও।

Example

box-shadow, opacity

Transform / Transition / Animation

Important
Important Most Used

24. Transform + Transition

hover interactions
Detailed Essential Note

Transform visual movement দেয়, transition change-কে smooth করে। Together তারা polished interaction তৈরি করে।

When / Where to Use

Card hover, button hover, image zoom, icon rotate — এসব জায়গায় খুব common।

Pro Tip / Common Mistake

সবকিছু animate করো না। Only meaningful hover/motion use করো।

Example
.card {
  transition: .3s;
}
.card:hover {
  transform: translateY(-6px);
}
Good to Know Less Use

25. Keyframe Animation

@keyframes, animation
Detailed Essential Note

Keyframes multiple animation stage define করতে দেয়। Complex motion-এর জন্য useful।

When / Where to Use

Loader, floating effect, fade in, pulse animation-এর জন্য use হয়।

Pro Tip / Common Mistake

Unnecessary animation site slow feel করাতে পারে। subtle use করো।

Example
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

.box {
  animation: fadeIn 1s ease;
}

26. Form Styling Basics

input, textarea, button, focus
Detailed Essential Note

Form usable, readable, and visually clean হওয়া জরুরি। Input spacing, border, focus state—এসব form UX improve করে।

When / Where to Use

Login form, contact form, signup form, search bar — সব জায়গায়।

Pro Tip / Common Mistake

Focus outline পুরো remove না করে better custom focus state দাও।

Example
input {
  padding: 12px;
  border: 1px solid #cbd5e1;
  border-radius: 10px;
}

input:focus {
  outline: none;
  border-color: #2563eb;
}
